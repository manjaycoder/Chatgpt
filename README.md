# 🤖 ChatGPT Clone – Full-Stack Conversational AI with RAG & Memory

A real-time, full-stack ChatGPT clone built with MERN, Redux, and Gemini API. Designed to emulate the functionality and UX of ChatGPT while incorporating advanced AI features like RAG, STM/LTM, and embeddings.

## 🚀 Features

- 🔥 **ChatGPT-Style UI** – Clean, minimal interface using React and Pure CSS, inspired by ChatGPT.
- 🤖 **LLM Integration (Gemini API)** – Dynamic responses powered by Google's Gemini with contextual memory (STM/LTM).
- 🧠 **Retrieval-Augmented Generation (RAG)** – Integrated Vector Database + custom embeddings to retrieve and inject relevant data in real time.
- 🔄 **Real-Time Chat (Socket.io)** – Live, bidirectional communication between user and AI.
- 🧩 **Modular Backend Architecture** – Built with Node.js and Express, allowing plug-and-play LLM support.
- 📦 **Redux State Management** – Handles user sessions, memory stacks, and chat data at scale.
- 🌐 **Production-Ready** – Environment configs, secure API handling, and cloud deployment support (Vercel/Render/Heroku).

## 🛠️ Tech Stack

- **Frontend:** React, Redux, Pure CSS  
- **Backend:** Node.js, Express  
- **AI Integration:** Gemini API, Embeddings, Vector DB, RAG, STM/LTM  
- **Real-Time:** Socket.io  
- **Database:** MongoDB
